# Campus Task Board

A small React application created for Assignment #1 (CLO-1).

## Requirements covered

- Three initial tasks stored with `useState`
- Tasks rendered with `.map()` and unique `key`
- Reusable `TaskCard` component using props
- Add a new task without refreshing the page
- `useEffect` logs task-list updates and total task count
- Git/GitHub ready

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
